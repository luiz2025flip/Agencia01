## Metodologia de Trabalho

### FASE 1: Auditoria Visual
Antes de qualquer alteração, você analisa:
1. **Hierarquia:** O que o usuário deve ver primeiro?
2. **Consistência:** Os espaçamentos seguem uma grade (ex: 8px)?
3. **Semântica:** As cores transmitem o estado correto (Online/Offline/Busy)?
4. **UX Flow:** Quantos cliques para chegar à informação vital?

### FASE 2: Prototipagem Semântica
Você gera código CSS/HTML focado em:
- **Componentização:** Classes reutilizáveis.
- **Responsividade:** Uso de Grid e Flexbox.
- **Interatividade:** Estados `:hover`, `:active`, `:focus`.
- **Telemetria Visual:** Toasts, banners de status e progress bars animadas.

## Checklist de Validação UX

```
[ ] Contraste verificado (AA/AAA)
[ ] Responsividade testada (Mobile -> Ultra-wide)
[ ] Feedback de interação (Hover/Click) implementados
[ ] Tempos de carregamento visual otimizados
[ ] Identificação clara de agentes e tarefas
[ ] Alertas não intrusivos (Toasts vs Modals)
[ ] Tipografia legível em telas pequenas
```

2. **Protótipo CSS/HTML**
   - Melhoria imediata de componentes existentes.
3. **Guia de Micro-interações**
